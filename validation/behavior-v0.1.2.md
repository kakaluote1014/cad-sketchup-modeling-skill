# v0.1.2 合成桌面演练

日期：2026-10-26。执行者为本轮维护者 Agent。实际读取更新后的 Skill，并对下列合成用户请求逐案生成下一步决策、拟执行动作及保护范围，再按状态和作用范围复核。不是独立评估 Agent、MCP 调用、离线几何模拟器或学生实机测试；下表数值均为测试输入，不是项目参数。未使用关键词匹配判定。

## D1：只改颜色，尺度未校验

输入：连接已能读取指定外墙组，只要求换浅灰色；没有尺度记录，不改几何。该组材质与另一栋共享。

本轮决策：重读文档、目标及材质关联，保护内存状态；为本组隔离需要修改的材质，再改色并检查透明对象是否保留。报告几何尺度未校验，不向用户索要无关尺寸表。

语义复核：另一栋及玻璃不应被共同重涂；无需重做 CAD 准备、全项目指纹或保存重开。符合该任务范围。

## D2：人工移动后继续

输入：用户把二层副本沿项目 X 移动1250mm并炸开一个子组，再说继续补窗上墙；旧 ID 失效。

本轮决策：读取实际路径、选择／层级与变换，在当前位置重新定位开口和墙顶，依据本项目标注补受影响对象；不按旧局部坐标在原位重造，不复用失效子实体。

语义复核：1250mm 是本场景人工改动，不应被恢复；只改指定副本。符合保护人工修改要求。

## D3：干净源文件切副本

输入：源模型已保存且 modified? 为 false，要求在新副本展开楼层。

本轮决策：核对源磁盘文件与目的地，制作不覆盖源件的备份及目标；打开目标后重读真实路径与层级，写入函数再次核对目标。先做代表楼层，再按首层／标准层／顶层差异展开。

语义复核：字节复制仅适用于已保存干净源件；不能仅凭副本文件已存在就向仍打开的源模型写入。符合边界。

## D4：内存有未保存成果

输入：磁盘文件仍是上午版本；用户下午人工改了入口，modified? 为 true；现在要切副本。

本轮决策：先把当前内存成果通过可用的保存副本能力保护到独立文件，验证成功；未命名则先明确保存到新位置。切换仍出现保存提示时不擅自覆盖／丢弃，先处理提示决定。

语义复核：复制上午磁盘文件不代表入口已备份；保护失败停止切换和写入。符合状态区分。

## D5：嵌套共享定义

输入：两栋共享父组件及内部窗框定义；只允许改第一栋的窗框。提案内部有大量相同栏杆。

本轮决策：检查共享路径，隔离第一栋需要局部编辑的父／子关系和材质，独立化后重新查子实体再修改。提案内部同规格栏杆仍可共享缓存定义。

语义复核：既避免传播到第二栋，也不把全部重复组件独立化制造模型负担。符合授权范围。

## D6：平面洞口正确，三维被遮住

输入：窗洞平面和墙轮廓正确；开新场景后窗洞消失，旧外观体量可见；板带又与上墙重复。

本轮决策：核对场景显隐、旧体量遮挡和窗底／顶、板带范围；在允许对象内协调墙板实体，保留既定墙轴和开口，按最终显示组合预览及读回。

语义复核：不能仅凭 bbox 或一张无遮挡截图结束；不能用隐藏旧层掩盖仍要求保留的实际冲突。符合联合检查。

## D7：家具参数只有平面范围

输入：设备表为 w=1800、h=700，字段含义未说明；门洞和通道已确定。用户授权完成公建这阶段。

本轮决策：不把 h=700 当设备实体高度；先完成有依据的墙、洞口和通道，设备保留平面占位并列出语义待核。关键设备尺寸需要时再补问，不停整阶段。

语义复核：没有虚构产品或供餐能力，也没有把局部未定扩大成全项目等待。符合区分设计与实现选择。

## D8：标签默认行为与旧场景保护

输入：标签 T 默认隐藏，但在旧场景 S 中保存为显示，T 在 page.layers 返回列表中；另一场景没有存标签状态。需要新增外观提案，保留旧场景。

本轮决策：不能由 T 在列表中推断隐藏；核默认行为、场景存储、父文件夹与对象实际显隐。新提案按约定设置相关场景可见性，检查旧场景结果；未存状态／nil 不直接判全显或全隐。新增替代家具场景分别只显示各自方案。

语义复核：保留旧场景的 T 显示，避免误归档；两套家具不叠加。符合 API 语义与保护要求。

## D9：修改超时，实际已完成

输入：创建12个同类对象的调用超时，重读显示目标范围已有12个且尺寸正确；用户期间又移动相机。

本轮决策：核位置与重复情况后检查保存，不再次创建12个，也不 undo 用户相机动作。若只读到部分对象，则定位缺项再决定补齐。

语义复核：没有因超时重复生成或回退人工动作。符合继续规则。

## D10：可选缺失与内部错误

输入：某栋设备组不存在但墙组齐全；另一次工具外层成功，内容为 Ruby 异常而非预期结果。

本轮决策：可选设备返回空集合且说明；必要墙组若缺失仍报错。内部 Ruby 异常使本次回读失败，停止依赖该结果的修改并定位问题。

语义复核：没有 nil.entities 崩溃式假定、吞掉必要缺失或把协议成功当业务成功。符合结果检查。

## D11：保存重开指纹差异

输入：文件 SHA 已变；两个旋转构件仅有 +0.0／-0.0 差别，另一墙点坐标真实改变2mm。

本轮决策：保留原始差异，使用相同字段、坐标系与精度规则比较，区分正负零和真实墙点变化；2mm 差异继续报告和核因，不自动容忍。另核场景与贴图资源，不靠纯几何指纹证明全部交付。

语义复核：不扩大忽略名单，不把文件 SHA 变化当几何变化或把全部变化归零。符合检查边界。

## D12：整阶段已授权，用户要求加快

输入：用户已确认住宅展开范围，代表户核对通过；标准层相同，首层入口和顶层屋面不同。

本轮决策：合并同类批次连续完成，差异部位分别核对；共墙明确归属，不每户问是否继续。批次交付一个当前模型入口和短摘要，大型数据留后台。

语义复核：减少无关等待，同时没有把首层、顶层按标准层盲目复制。符合效率与准确性边界。

## D13：未接通就要求做白模

输入：工具列表为空，学生给了一张房间图，要求直接开始。

本轮决策：进入安装／排查，只读检查环境；缺依赖说清来源和影响，由学生选择安装。不宣称已读取或生成模型，不用 computer use 绕过目标与尺寸确认。

语义复核：不因新进阶规则失去原连接门槛，也不默认安装软件。符合原有入口。

## D14：多层批量，样板墙线有缺口

输入：要求复制20层；样板一段墙线不闭合，墙高未知；只给旧案例的墙高，未确认用于本项目。

本轮决策：定位缺口并区分门洞和误断，补当前图纸依据及墙高；暂停受影响批量，可继续不受影响的只读检查。不上来补死全部缝，不套旧案例高度，不声称结构或消防通过。

语义复核：批量推进以有依据的代表对象为前提，数量大不降低检查。符合原始 CAD→SU 教学边界。
