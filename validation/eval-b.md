# B1–B6 独立前向行为演练

日期：2026-10-08。

本报告是依据合成输入作出的模型决策和动作计划，不是实际工具执行。每案独立，不沿用其他案的连接、授权、参数或结果。实际仅读取 Skill、相关教程和 scenarios.md，并新建本文件；未使用真实 CAD、SketchUp、MCP、网络、安装、配置或模型脚本。没有预设通过分数。

使用材料：`cad-sketchup-mcp/SKILL.md`、`validation/scenarios.md` 中 B1–B6，以及各案列明的教程。Skill Creator 的 Independent Forward-Testing 仅用于确定评估方法，没有用于代替被测 Skill 的建模规则。

动作记法：`get_version` 和 `get_model_info` 是教程明确列出的工具名。其余“查询”“保存”“修改”等表示拟向模拟 MCP 请求的功能，教程未提供完整工具 schema，本报告不编造接口名或可执行脚本。所有后续动作均为条件计划，没有模拟成功回执时不填写完成结果。

## B1：比例异常仍要求先建墙

### 按需读取

- `references/modeling.md`：继续建模前读现场；已有成果的尺度修正、两段尺寸冲突和暂停范围。
- `references/cad-preparation.md`：检查端点、单位、不同区域尺度和非等比变形；全模型缩放仅限空白准备文件。

### 实际决策与模拟动作顺序

1. 模拟 `get_version`、`get_model_info` 读取当前连接、文档标题和路径，确认当前选择是否为用户要求的楼层，查询编辑上下文、父级层次和实例变换。已有二层墙体须被纳入影响检查。
2. 查询 A、B 的具体原图位置、模型对应端点及世界坐标测量，区分底图和已有墙体是否在同一层级、是否受不同实例变换影响。核实 A=8000 对 800、B=200 对 40 的测量对应关系。
3. 计算两段所需倍率分别为 10 和 5。输出单位 mm 不能解决该冲突；任何一个统一倍率都不能同时校正两段。报告这项证据，暂停受影响目标的新墙体写入。
4. 继续只读定位：端点选错、导入单位、嵌套缩放或局部变形哪个原因得到证据支持，列出影响底图、墙体及其他楼层的范围。没有依据，不挑一种原因当事实。
5. 若之后形成可核查的局部修正方案，先说明受影响对象和已有成果处理方式，取得明确修正范围，再保存包含当前成果的可恢复备份，进行局部修正。重新读回两段及相关墙体尺寸后才考虑本次建墙。

### 是否写入及范围

当前不写入。不直接执行全模型缩放，不以用户“先建墙”忽略已知错误比例。未来的修正范围取决于诊断和明确授权，本案未具备该条件。

### 给学生的简短回复

> 这两段尺寸需要的倍率不同：800→8000 要乘 10，40→200 要乘 5，先建墙会沿用错误底图。我先只读核对端点、导入单位和副本变换，并检查已有二层墙体受影响的范围；原因与修正范围确定后再继续建墙。

### 无法确认与技能文本问题

无法确认 A、B 的端点、方向、嵌套层级、是否量到同一底图，以及已有二层墙体是否随底图变形。不能由两个比值单独证明错误成因。教程提供了明确停写和诊断原则，但没有具体查询变换和几何的接口；实际执行须检查现成 MCP 能力，缺能力则要求学生手工测量或提供截图。本案停写来自输入信息不足，不是 Skill 要求把全部其他检查一起停掉。

## B2：多窗口和“右边首层”歧义

### 按需读取

- `references/install-connect.md`：多开窗口时匹配服务进程、端口和文档；错误文件不得杀进程或停其他服务。
- `references/modeling.md`：以文档、选择、位置和层级定位；“右边那个”不明确时只检查。

### 实际决策与模拟动作顺序

1. 模拟 `get_version`、`get_model_info` 读回当前连接的版本、标准层文件标题和路径，查询选择为空及两个右侧副本的层级、位置。将这些信息作为当前连接的事实，不把屏幕另一窗口当作 MCP 的目标。
2. 向学生报告连接目前读到标准层文件；请学生在希望修改的首层窗口选中目标副本，并给出该窗口文件名或路径、所需修改构件。需要时让学生查看这个窗口已有 MCP Server Settings 的 Host/Port，仅读取，不启动、停止或改配置。
3. 若确认有对应的现成连接，模拟在该连接上依次 `get_version`、`get_model_info`，重新读取选择、层级、位置和变换。匹配目标文件与选中首层后才继续。
4. 目标连接不存在或对应关系仍未知时，说明需要确认连接；本轮不自行安装、启动或更改配置。目标明确后，再按具体“改什么”核对两段尺寸与参数、备份和样板，不从“改首层”自动推导完整重建任务。

### 是否写入及范围

当前仅只读，不写模型或配置。即使标准层文件中存在两个右侧副本，也没有依据任选其一。后续仅限匹配文件中的选定首层副本及学生明确的构件修改。

### 给学生的简短回复

> 当前 MCP 读到的是标准层文件，另一个首层窗口还未确认与连接对应。请在要改的首层窗口选中目标副本，告诉我文件名和具体要改的构件；我重新读到同一文件与选择后再操作。

### 无法确认与技能文本问题

未知窗口与端口对应关系、首层实际路径、两个副本的用途以及“改”的具体内容。Skill 明确覆盖这些歧义；连接教程没有枚举多连接的选择工具，因此第 3 步依赖现场是否存在可选的对应连接，不能宣称已切换成功。

## B3：超时后重做八个窗框，期间有人移动一个

### 按需读取

- `references/modeling.md`：超时不表示未执行；重读实际数量、尺寸与位置，保留人工改动；不得盲目重发或 undo。

### 实际决策与模拟动作顺序

1. 模拟 `get_version`、`get_model_info` 确认 SU 已响应且仍是本次文档；读取目标楼层、副本、选择和编辑上下文。查询当前窗框的实际数量、位置、尺寸、定义关系与变换，不复用超时前的实体 ID。
2. 将当前窗框与原来八处目标开口逐个匹配。专门核实学生移动的窗框及其新位置，不将其旧位置的空缺直接认作失败；如无法从模型识别，要求学生选中移动对象或标注。
3. 重新核对两段原图尺寸和窗框参数，区分已完成、部分完成、重复或异常，以及无法确认状态的对象。数量等于八仍不证明八处均正确，数量少于八也不立即批准重发整批。
4. 全部已完成且尺寸正确时，仅安排阶段保存和预览；保留被移动窗框，并列明其新位置是否还需用户核对。
5. 只有明确识别出尚未执行的目标，且移动后的布局不与其冲突，才保存包含人工移动的当前备份，再以单一串行任务补这些确定缺失的窗框。补前重读，补后检查数量、尺寸、位置和非目标状态，确认阶段 SKP 非空并提供预览。
6. 完成状态或布局意图仍不能确认时，停在检查报告，不撤销、不恢复旧文件、不重建整批。

### 是否写入及范围

当前不进入创建写入；“重做一次”的直接请求需要先用实际状态判定范围。条件满足后，只补确定未完成的窗框，不把人工移动对象移回，不重复创建已存在对象。备份和阶段保存也只是拟议动作，尚未发生。

### 给学生的简短回复

> 超时可能已经建出部分或全部窗框，我先读回八处的实际数量、尺寸和位置，并保留你移动的那个。确认缺失后只补缺项；现在不重发整批，也不撤销你的移动。

### 无法确认与技能文本问题

未知已完成数量、部分窗框的完整程度、移动对象、新位置及原八处开口依据。教程对超时与人工修改的顺序清楚，真实匹配仍需要可查询的几何或学生标注。没有新读取结果，不能给出具体补建数量、实体列表或“已恢复”结论。

## B4：给含玻璃的共享立面父组统一涂墙材质

### 按需读取

- `references/modeling.md`：材质分类、透明度、前后面与继承；共享父级独立化及修改后重读。

### 实际决策与模拟动作顺序

1. 模拟 `get_version`、`get_model_info` 确认当前文件、选择的立面父组、目标楼层和副本；查询两段尺寸、层级、实例变换及共享定义／副本关系。核实“父组共享副本”的实际对象类型，不只凭“组”的称呼判断其是否独立。
2. 查询墙、玻璃、窗框的几何和现有材质，读取墙面与玻璃的前后面材质、父级继承和透明度，确定外墙面的方向。既有透明玻璃作为须保留的状态。若不能区分墙面或外侧面，要求学生标注后再写。
3. 将请求收敛为选定立面实例的外侧墙面使用浅色材质。浅色未指定可沿用用户已有的明确浅色墙材质；没有时提出普通浅色样板，由学生确认色调，不把任意 RGB 当项目事实。未指定要改共享副本，因此保护副本，不给父组整体上不透明材质。
4. 模型修改前保存含当前未保存改动的可恢复备份。若需要修改共享几何的材质，先使相关目标实例及必要共享父／子定义独立，再重读新的对象层级、引用、材质与尺寸，不继续使用旧子实体引用。
5. 建立目标墙面使用的材质或使用已确认材质的独立副本；不直接改其他部位共用材质的属性。先对一个已分类的外墙面试样，读回其前后面、位置和材质，并检查玻璃、窗框和非目标副本未变。
6. 样板确认及客观检查符合要求后，再涂同一选定立面的已确认外墙面。读回透明玻璃从内外视图的表现、前后面和继承关系、其他副本状态，保存阶段 SKP，导出预览并恢复改变的视图。

### 是否写入及范围

该请求授权墙面材质修改，条件满足后可写入选定立面的外侧墙面，以及为隔离其影响所需的相关实例独立化。当前合成信息缺少墙面分类、外侧方向、两段尺寸、备份和色调依据，尚不能实际开始写入。玻璃、窗框、其他共享副本的材质不在修改范围；不能通过父组整体赋色实现。

### 给学生的简短回复

> 我会把这处立面的外墙面改为浅色，保留玻璃透明度和窗框材质。先检查前后面、材质继承和共享副本，备份并隔离会受影响的实例，再做一面样板；不会把整组玻璃一起涂成墙色。

### 无法确认与技能文本问题

未知当前“父组”的真实类型、共享层级、哪些面属于外墙、外侧面朝向、既有材质名称和色调，以及两段图纸尺寸是否可获得。Skill 把“两段原图尺寸”设为每次写入的共同前提，未给仅改材质的例外；本案严格遵循时会在缺尺寸处等待，即使任务没有改变几何。这是实际教学中可能造成额外阻塞的边界，应由维护者评估，不在本次测试中自行豁免或改规则。

## B5：天正菜单不同，以及是否必须胚子助手

### 按需读取

- `references/cad-preparation.md`：局部导出、菜单跨版本待核，以及胚子助手可选。
- `references/install-connect.md`：已握手且读模型成功即可跳过安装；连接不依赖封面插件。

### 实际决策与模拟动作顺序

1. 使用本案已给的握手和模型读取成功事实，解释当前 MCP 可读；不反复跑安装检查，也不要求安装胚子助手。无需为回答这两个问题请求 MCP 写入或创建测试方块。
2. 告诉学生暂不改用整图导出，保留原 CAD，仅整理目标楼层副本。请学生提供本机天正版本和菜单／导出对话框截图，或查看对应版本帮助，确认是否有局部导出及其实际选项。本评估禁止网络，因此不联网检索菜单。
3. 若本机有对应局部导出，指导学生只选目标副本，设置清楚文件名，保留原图并检查导出内容；“全部内容”仍限框选范围。若已存在可靠普通 DWG，可以直接准备导入，不为流程强制补装天正。
4. 学生在独立空白 SU 文件导入后，拟请求只读 `get_model_info`、目标底图的两段尺寸和边界／法向查询。正确则不缩放、不强制重复炸开；错误按明确尺寸检查原因。没有胚子助手，指导用原生线工具补图纸明确缺线，使闭合共面区域成面，检查正反面、墙和房间分类。
5. 底图完成后由学生保存可编辑 SKP，下一次继续前再只读确认文件与两段尺寸。本案尚未到导入完成或保存完成，不填成果路径。

### 是否写入及范围

当前只是教学答疑，不控制 CAD／SU，不写模型、安装或配置。未来整理和导入指导仅针对目标楼层副本与新空白准备文件；不会未经授权将整张 CAD 导出或在已有成果全选炸开。

### 给学生的简短回复

> 你这台 MCP 已经握手并读到模型，胚子助手不是连接依赖，只是可选封面辅助。天正菜单随版本可能不同，先保留局部导出目标楼层的范围，别直接改成整图导出；给我版本和菜单／导出对话框截图后再对应操作。没有胚子助手也能用 SU 原生工具检查闭合并封面。

### 无法确认与技能文本问题

未知天正版本、具体菜单和导出选项、现有普通 DWG 是否可靠、DWG 单位及两段尺寸。Skill 明确承认跨版本菜单证据不足，并提供截图／帮助核对的路径，不能把作者的菜单文字套到本机。不能凭已读模型推断尚未准备的 DWG 已可正确导入。

## 观察到的执行边界

- B1、B2、B3 的下一步是只读诊断；合成输入不足以批准确定范围的写入。B4 有局部材质授权，但需先确认墙面、隔离共享影响并满足共同写入前提。B5 是答疑与底图准备指导，B6 是证据表述。
