# v0.1.2 迭代验收

日期：2026-10-26。范围为独立 Skill 仓库内教学文件、打包工具与隔离输出。没有连接 CAD／SU、运行历史项目脚本、安装依赖、改全局配置、提交或推送。

## 改动与取舍

- 主入口只增加任务检查深度、连续推进和进阶参考路由；保留原 CAD→SU 流程、新手练习与第三方 MCP 归属。
- 建模参考合并多层差异、共墙、墙板洞口楼梯联动、源模型隔离、互斥场景与简短交付。
- 新增一份进阶参考，包含安全保存切换、一次单位转换、嵌套坐标、operation、共享定义、真实结果、标签默认行为及指纹范围。不复制项目模型、路径、脚本和默认尺寸。
- 学生提示词不固定 SketchUp 年份、套餐或模型。旧的未提交通用提示词和旧 ZIP 保留，另建本版提示词。
- 骑楼及社区交接属于经验来源；学生截图属于有限反馈；本轮校验和桌面演练属于新证据，三者分开记录。
