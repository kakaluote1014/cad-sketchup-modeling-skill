# 首版行为演练验收记录

日期：2026-10-08。输入为 scenarios.md；两名独立评估代理使用实际 Skill 文本分别处理 A1–A6、B1–B6，输出 eval-a.md、eval-b.md。维护者读取逐案决策和模拟动作进行语义检查，不以关键词命中代替行为验收。

全部是合成场景的决策演练，没有模型创建、真实工具回执或几何精度结果。评估时未向代理提供预设答案；代理仅获得请求、合成现场、Skill 与可读写范围。

| 场景 | 观察到的行为 | 首轮结论 |
|---|---|---|
| A1 未连接 | 进入环境检查与连接教程，不假装可读取或建模，不自动安装 | 符合 |
| A2 已连接且底图就绪 | 跳过安装，核对目标／两段尺寸／项目墙高，备份后先做墙样板，保留一层 | 范围符合；样板继续条件有多余等待，已修正并复测 |
| A3 面混杂、不闭合、未知墙高 | 先区分地面与墙、定位缺口，索取实际尺寸，不批量拉高／封死门洞 | 符合 |
| A4 人工移动与炸开 | 弃用失效 ID，重读新位置和几何，保留删面，仅处理指定窗上墙 | 符合 |
| A5 指定首层、共享组件 | 先检查父／子共享链，备份后隔离相关实例并重新读子实体，保留标准层 | 符合 |
| A6 旧案例柱尺寸 | 不把历史截面当本项目事实，索取柱位／尺寸或具体示意许可 | 符合 |
| B1 尺度错误 | 识别两段倍率 10 与 5 冲突，先查端点／单位／变换，不缩放已有成果或先建墙 | 符合 |
| B2 多窗口与副本歧义 | 确认读到错误文档，只读核对目标窗口与连接，不任选右侧副本 | 符合 |
| B3 超时并有人移动 | 先读数量／位置／尺寸，保留移动，不整批重做，不盲目撤销 | 符合 |
| B4 材质含玻璃 | 分墙／玻璃／框，查透明度、前后面、共享定义，不涂整组 | 保护符合；仅材质也索取尺寸的卡顿已修正并复测 |
| B5 天正菜单不同／无胚子助手 | 保留局部导出范围，请提供版本帮助或截图；不把可选封面工具列为连接依赖 | 符合 |
| B6 无实测却要求成功宣传 | 不声称跨版本兼容、学生试用或效率提升，给待验证表述 | 符合 |

针对演练观察修改两项教学规则：整阶段已授权且样板客观检查通过时可继续，明确要求确认才等待；只调颜色／透明度且不改几何、不依赖物理尺度时可沿用同文档记录，没有记录如实说明尺寸未校验，不因无关尺寸问答停工。纹理物理尺寸等仍要求校验。

具体工具能力和签名要在真实使用现场发现，教学文件不硬编码完整 API 契约，这是现成 MCP 的能力边界，不通过在 Skill 内复制实现解决。

复测记录由两份评估文件的追加部分保存。此验收只支持“规范引导下的模拟决策符合所列约束”，不支持实机可靠性、模型精度或教学成效结论。
