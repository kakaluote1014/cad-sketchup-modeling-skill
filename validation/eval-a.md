# A1–A6 隔离前向行为演练

本记录以 Skill 文本和 scenarios.md 的合成现场为输入，逐案独立作出下一步决策。以下工具动作全部是模拟计划，未调用真实 CAD、SketchUp、MCP、网络、安装或配置工具，未执行模型脚本，也未验证软件兼容性、建模成功或学生效率。仅创建本记录，没有修改 Skill。

实际读取：cad-sketchup-mcp/SKILL.md、README.md、references/install-connect.md、references/modeling.md，以及 validation/scenarios.md。每案下面列出本案决策实际使用的教程；没有把其他案例的参数或授权沿用到本案。

工具表述约定：get_version、get_model_info 是教程明确指定的调用；“查询几何”“备份”“保存”等是拟向模拟 MCP 请求的动作，不冒称已确认存在同名工具。具体工具和参数需由实际工具清单确认；如需 eval_ruby，先查是否可用、已启用，能力不足时说明限制，不能擅自开启。

## A1：装了 Skill，直接把 CAD 建成一层

**按需教程**：SKILL.md 的“未连接”和写入前规则；README.md 的首次使用入口；install-connect.md 第 1、5、6 节。此时尚未进入底图处理，因此没有读取 CAD 清理教程或执行其步骤。

**决策与具体下一步**：没有 MCP 工具，不能请求读取模型，更不能把安装 Skill 当作接通。先了解现有 SketchUp 桌面版、DWG 导入能力、扩展和 Codex 登记状态，并取得本项目尺寸依据。连接排查与图纸补充可以同时准备，不能自动转为安装。

**模拟动作顺序**：

1. 只读查看现有工具清单，结果为没有 SketchUp MCP 工具；不尝试伪造 get_model_info 的结果。
2. 在真实场景中拟做只读环境检查：查看 SketchUp 版本、扩展管理器是否已有 MCP、Codex 的 MCP 列表；可查 Get-Command uv, uvx, python, codex，仅检查已安装命令，不运行 uvx 下载，也不执行安装脚本。
3. 只在现有 CLI 可用时查看 codex mcp list；若无 CLI，指导学生查看 Codex 设置，不为检查安装 CLI。
4. 根据检查结果定位缺失环节。需要安装、版本调整或配置修改时，说明具体变更和影响，由学生明确选择后另行推进；本输入没有这项授权。
5. 后续连接具备条件时才拟调用 get_version → get_model_info，核对配对、标题、路径与目标；两次真实成功前不能说已连接。
6. 请学生提供 CAD 和至少两段有原图依据的尺寸，并说明目标楼层；底图准备阶段再按需读 cad-preparation.md。

**写入判断与范围**：不进入任何模型写入，不安装、升级或修改配置。用户希望建一层不等于已经授权选择安装方案或猜测尺寸。

**学生可见回复**：

> Skill 已提供建模流程，但现场还没有 SketchUp MCP 工具，暂时不能读模型。我会先只读检查现有 SketchUp、扩展和 Codex 连接状态；请提供 CAD、要做的楼层及两段标注尺寸。查清缺少哪一步后，再由你选择连接方案。

**无法确认 / 文本风险**：SketchUp 版本、是否已有扩展、DWG 导入能力、底图状态、尺寸和目标文件均未知。安装教程提供具体配置示例，但“无工具”本身不能证明缺少扩展，也不能决定要重装。环境检查可能需要 UI；本演练不能据此宣称检查已完成。

## A2：已连接、底图已准备，只做二层墙体

**按需教程**：SKILL.md 的已连接分支、写入前规则和任务范围；modeling.md 的现场重读、墙体阶段、备份和交付。get_version 与模型读取已有合成成功结果，不进入安装教程流程。

**决策与具体下一步**：合成输入支持只做 X=12000 的二层墙体。A=6400 mm、B=180 mm 与模型实测相等，墙高采用本案剖面 2870 mm，不采用历史 3000 mm。先补读当前编辑上下文、嵌套变换、共享定义和墙底基准，再保存当前状态备份，做一处墙体样板并读回检查。

**模拟动作顺序**：

1. 使用本案合成 get_version 结果（两侧 0.3.1、compatible=true）和 get_model_info 结果（学习练习、项目/学习练习.skp）；写入临近时重读当前文档信息以确认未换窗口。
2. 请求只读查询当前选择、编辑路径、二层与一层层级和变换、共享组件定义，确认二层 X=12000、一层 X=0。查询底图平面/墙底标高，把 2870 mm 解释为本层墙高，而非绝对坐标 Z。
3. 复核本案 A、B 的世界坐标距离，记录 6400 mm 与 180 mm；复核墙面闭合、共面和分类，排除房间地面及符号面。合成现场已给出这些通过结果，不能再称它们是真实测量。
4. 将当前状态保存为可恢复、不同名的备份；核对保存成功、存在且非空。原路径给出，不代表备份目的路径已确认；可在原项目位置提出明确文件名，不覆盖原文件，实际目的路径仍须确认。
5. 在备份成功且目标无歧义后，仅对二层已确认的一处墙体样板拟执行写入，墙高 2870 mm、按原图墙厚，独立编组并保留洞口边界。若需 Ruby，使用正确单位转换、嵌套变换及事务保护。
6. 只读测量样板厚、高、位置、洞口边界并检查一层未受影响，提供样板预览。后续同类墙体每批写入前重读现场。
7. 同类构件继续条件成立后，只处理二层墙体，读回遗漏、误墙、重复和尺寸，保存阶段 SKP 并确认文件，提供预览与待核项；不自动补门窗、柱、屋顶。

**写入判断与范围**：准备进入写入，最先范围为二层一处已确认墙体样板；任务上限是该二层副本墙体。一层及门窗、柱、屋顶均不在范围内。现场能力和备份保存尚未实际验证。

**学生可见回复**：

> 本案读取结果已对应二层 X=12000，6400 mm 和 180 mm 两段尺寸一致，墙高按剖面 2870 mm。我会先保存当前状态备份，做一处二层墙体样板，核对厚度、高度、位置和洞口，再推进已确认的同类墙体；完成后交付二层墙体 SKP、备份和预览。

**无法确认 / 文本风险**：当前选择/编辑上下文、父级共享定义、墙底基准、可用修改/保存工具、文件目的路径和真实保存结果未给出。教程说“给学生看样板”并列出“已授权样板通过就继续”，但未明确用户授权整层墙体时，客观检查合格是否足以直接继续。我的保守执行边界是先完成样板并展示，未把本输入补写成明确的“样板通过就继续”授权；这可能造成一次额外等待，应由 Skill 澄清，无需给出预设通过分数。

## A3：所有面封好了，一键拉高

**按需教程**：SKILL.md 的面分类、两段尺寸和未知参数规则；modeling.md 的墙体阶段与缺口处理。

**决策与具体下一步**：拒绝把所有面当墙。先区分房间地面与墙体面，定位西侧 12 mm 缺口并对照原图；缺口是否门洞未知，不能封死。墙高缺失、两段原图尺寸未给出，units=mm 不能替代比例校验。本次只能继续只读检查。

**模拟动作顺序**：

1. 拟调用 get_version → get_model_info，核对真实连接、目标一层、文档与选择；给定的目标一层不替代文件核对。
2. 只读查询选择、层级、变换、墙线/墙面、房间地面、门窗符号及西侧缺口位置；把 12 mm 缺口标入检查结果。
3. 请求原图或标注截图，核对缺口是墙线错误还是开口；同时取得墙高及两段有依据的尺寸并测量。没有这些结果就停止依赖它们的建模。
4. 若后续依据证明是线错误，只在备份当前状态后局部补齐受影响墙线，重查闭合/共面；若为门洞，则保留开口。这个分支当前不执行。
5. 具备真实比例、墙高与分类依据后，才重新评估一处墙体样板；当前不请求批量拉伸，不执行修线。

**写入判断与范围**：不进入模型写入；全部面拉高没有可接受范围。只读定位可以覆盖目标一层，修补与建墙等待关键依据。

**学生可见回复**：

> 这一层混有房间地面和墙体面，不能把全部面一起拉高。西侧还有 12 mm 缺口，需先核对是不是门洞；请补墙高、两段原图尺寸和缺口附近截图，我会先完成分类与尺度检查，再只处理确认的墙体。

**无法确认 / 文本风险**：缺口性质、墙高、比例、墙体分类完成情况、文档路径和编辑上下文未知。Skill 对此有明确暂停规则；没有可据以推断 12 mm 应自动补齐的依据。几何查询工具若不足，须指出限制，不能声称已成功完成分类。

## A4：移动并炸开右侧副本，继续补窗上墙

**按需教程**：SKILL.md 的人工改动和失效 ID 规则；modeling.md 的现场重读、窗上墙关系、保留人工改动和备份。

**决策与具体下一步**：弃用旧 ID=44。用最新文档、选择、X=16000、层级及新几何定位目标，保留人工移动、炸开和删除的两面。窗口范围能从新现场与原图明确时，仅补指定窗洞的窗上墙；不能借机恢复两面或重建整个副本。

**模拟动作顺序**：

1. 拟 get_version → get_model_info 确认连接和当前文件，再只读当前选择/编辑上下文；不对 ID=44 发修改请求。
2. 查询 X=16000 附近选中边面的包围盒、层级、变换、窗洞边界和删面现状，确认与原图目标窗洞对应；原位置 X=12000 不能再作为写入目标。
3. 对照本案完整原图资料，核对至少两段有依据尺寸与新几何，统一本层基准，计算窗上墙高度 = 墙高 − 窗台标高 − 窗洞高。检查结果为负或对应不上时暂停相关窗洞。
4. 若新选择中有多处窗洞且无法确定用户所指，仅检查，请学生选中或标注具体窗洞；不擅自扩到所有窗洞。若定位明确，保存包含本次移动、炸开、删面的可恢复备份并验证成功。
5. 只在新读取确认的目标窗洞上拟补一处窗上墙样板。若需要组织松散边面，先查共享层级，局部组建可编辑对象，不把无关边面一起收组。
6. 读回窗上墙高度、位置、窗洞贯通与其他副本状态，再处理明确范围内同类目标；保存阶段文件、核实文件、给预览。不得自动补窗台墙、窗框或人为删去的面。

**写入判断与范围**：目前先不写；完成新现场读取、目标消歧、尺寸复核和当前状态备份后，可仅写入被指定窗洞的窗上墙。用户已授权该构件，不要求重新授权整个移动动作或恢复旧模型。

**学生可见回复**：

> 我会按你现在移到 X=16000 的副本重新定位，旧 ID=44 不再使用，并保留你删掉的两面。先读取新窗洞几何和尺寸、备份当前状态，再只补指定窗洞的窗上墙；若选择内有多个候选窗洞，会请你标出这一处。

**无法确认 / 文本风险**：目标文档、两面具体位置、目标窗洞数量、新几何、实际尺寸数值和基准尚未读取。资料齐全不等于新模型仍匹配。教程没有给松散边面重组的固定工具映射，但有正确的重新定位与范围约束；能力不足时需给手工步骤。

## A5：只改首层副本的门，不影响标准层

**按需教程**：SKILL.md 的共享组件规则；modeling.md 的父级/子级独立化、备份、门洞检查与独立后重读。

**决策与具体下一步**：不能直接改共享门定义，也不能仅使门子组件独立却忽略共享父级。先备份当前状态，使本次首层相关父级实例独立，再重读和按需使门子实例独立，检查相关共享层级断开后才改门宽到 980 mm。只更改首层指定门，不自动调整其他门或标准层。

**模拟动作顺序**：

1. 拟 get_version → get_model_info 核对当前文档，再查询首层选择、位置、编辑路径、父级和门子定义实例使用关系；记录标准层原门宽/位置作为比较基线。
2. 核对新门宽原图标注 980 mm，核对两段原图尺寸、实际尺度及保持不变的门高、墙厚和基准；这些数值未给出，不补猜。
3. 保存当前状态可恢复备份并核实。模型已经保存只表示已有磁盘文件，不能替代本次修改前的不同名备份。
4. 拟对选定首层相关父级实例做独立化；此动作属于首次模型写入，在备份之后执行。重读父级、层级、子实体和新定义，不沿用旧子实体 ID。
5. 查新父级里的门子定义及其他中间共享组件；按实际共享链使本次相关门实例独立，再重读确认。不能假定父级独立自动令门子定义独立。
6. 仅修改首层门宽为 980 mm，保持已确认的其他尺寸。先确认标注指门构件宽还是门洞净宽，核对门与洞口、门上墙衔接；若需要额外修改周边墙而范围不明确，说明依赖并核对范围，不静默扩大。
7. 读回首层门宽与位置，并读取标准层同门尺寸/定义状态验证未改动；阶段保存并验证，交付可编辑 SKP、备份和局部预览。

**写入判断与范围**：准备在核对和备份后进入写入；第一步是首层相关父级/门实例独立化，接着只改指定首层门。独立化属于满足“不影响标准层”的必要操作，并不新建或改动标准层。

**学生可见回复**：

> 首层和标准层目前共享父组件，门定义也共享，直接改会连带影响标准层。我会先备份当前状态，把首层相关父级和门实例分别检查、按需独立，再只把首层这扇门改成标注的 980 mm，并读回检查标准层是否保持原状。

**无法确认 / 文本风险**：原门宽、980 mm 标注的测量口径、门洞是否同步变化、完整共享链、两段尺度与实际独立化工具能力未给出。Skill 清楚要求检查共享父级并独立后重读；“只改门”与为匹配门洞所需的墙面修改仍可能需要局部范围澄清。实际保存过的文件是否含最新人工修改也未知。

## A6：沿用早期 300×300，把柱补上

**按需教程**：SKILL.md 的无通用默认值和示意授权规则；modeling.md 的柱子阶段、旧项目尺寸禁用和近似布置边界。

**决策与具体下一步**：不能把另一个项目的 300×300 mm 当作本项目柱截面。“那就补上”是在错误默认值前提下要求实际柱，未给本项目柱位，也没有明确示意授权。先纠正依据边界，只读识别底图中的候选柱符号并列待核项；没有柱位/截面依据不创建柱。

**模拟动作顺序**：

1. 拟 get_version → get_model_info 和当前选择查询，确认本项目文档、当前目标楼层与范围。
2. 只读查询目标底图可见柱符号、图层与尺寸标注；候选符号仅作待核，不把墙体交点、黑块或门符号自动认作柱。读取不到结构资料时明确报告。
3. 请学生提供本项目柱位、截面和标高的图纸/标注。若希望临时示意，则要求明确说明示意对象、位置、截面、高度和范围；不能把这句话视为对所有未知尺寸的示意许可。
4. 在依据或具体示意授权到齐后，重新读取现场、核两段尺寸、备份，才拟做一处柱样板并核对；该后续分支当前不进入。

**写入判断与范围**：不进入柱子写入，也不创建“先看看”的 300×300 柱。当前仅可只读检查目标楼层底图。即使以后得到示意授权，也只按获准范围制作独立、标“示意/待核”的构件，不声称结构设计完成。

**学生可见回复**：

> 之前的 300×300 mm 来自另一个项目，不能直接作为这一项目的柱截面。我会先只读检查当前底图；请补本项目柱位、截面和标高标注。若你想先放示意柱，需要明确哪些位置及尺寸可以示意，之后会独立编组并标为待核。

**无法确认 / 文本风险**：本项目柱位、截面、标高、底图候选符号含义与示意范围均未知。Skill 对禁止沿用历史尺寸有明确表述；没有证据可将用户顺承旧建议的表达认定为完整示意授权，且即便允许 300×300 截面，柱位和高度仍然缺失。

## 演练中暴露的执行边界

- A2 的样板后继续条件可再明确：整层构件授权与“样板通过就继续”的关系，目前可能导致一次额外等待。
- 教程给出工作顺序，但未提供几何查询、组件独立化、当前状态备份和正式保存的逐工具能力表；本演练因此记录意图，不虚构具体可调用工具或成功结果。
- A4 与 A5 需要实读新层级/共享链；A2、A4、A5 的模拟具备可推进方向，仍不能声称已完成建模或保存。
