# v0.2.0 住宅路线迭代验收

日期：2026-10-29。制作校验范围为教学仓库、原创练习和隔离文件检查；没有安装／升级／卸载软件、修改全局配置、调用真实CAD/SU、重新建模或删除旧交付。完成校验后，按用户明确授权提交、推送、创建教学试用版Release并将仓库公开；最终发布状态以GitHub为准。

## 本次交付

- 保持现成第三方MCP与用户教学工作的归属；安装示例与保存行为同步到查证的0.4.0固定版，旧连接先检查、不强制升级。
- 住宅按需路线覆盖单户、标准层、首层／顶层差异、指定整栋；新增人工移动／炸开后续建的具体检查步骤。
- 原创住宅教学片段有原图DXF、清理参照、示意；先一层、后自选三层差异，避免未经要求继续。不是完整住宅设计或合规方案。
- 保留CAD准备原流程、入门资产、UI元数据、历史压缩包及历史试用提示词；新增v0.2.0提示词。
- 同版补充圈选截图＋参考样板的局部修改教程：目标A／参考B、叠置对象识别、样式与尺寸分开、共享保护、按授权批次和局部前后对照。方法来自用户与朋友的日常交流，不登记为实机验收，也不把聊天原图打进包。
- 同版加入可选模型分工与交接教程、Flash基础建模／Sol接手审查两段指令；交接时机、必要说明、重读现场与单一写入者明确化。不实际调用指定模型，不改提供商配置，不作为跨模型能力或成本试验。
- 项目本地习惯记录及空白模板，明确读取／初始化／增量更新／纠正／忘记、当前指令优先、项目尺寸不作默认；私人记录排除提交与打包，不修改公共Skill或模型权重。

住宅静态几何结果见 [residential-geometry.json](residential-geometry.json)：原图182实体、参照170实体，去除12条说明后几何相同；R2004、INSUNITS=4、共面Z=0、墙域分类及闭合、5个门洞／3个窗洞边界、主体板／VOID／阳台边界、两跑各9条鼻线与平台通过。DXF审计错误与修复均0。PNG为1920×1440，解码并目检；不是实际软件截图。

墙域静态面积：外墙5540000、共墙1340000、内墙993600 mm²，按独立依据逐网格检查；不以固定SU面数判断完成。门上墙750、窗上墙450、平台1500／终点3000等只算术核对，不是实际三维模型测量。

检查器的7个内存损坏反例均被拒绝：错误单位、缺墙边、缺VOID边、阳台错位、缺楼梯鼻线、门洞边界错位、墙线不共面。仅验证静态检查器的识别能力，不验证MCP会自行修复它们。

[10案文本桌面推演](behavior-v0.2.0.md)已由维护者逐案生成决策并语义复核，覆盖未连接、已连接、混版、尺度错误、缺线／未知尺寸、人工修改、错窗口、共享定义、楼梯板洞、超时。不是独立Agent或实机行为测试。

同版补充L1–L6共6案文本桌面推演并语义复核，涉及圈内叠置构件、A/B不同尺寸、嵌套共享、定位歧义、有限同类批次和只看图讨论。推演为新增合成输入，和作为方法来源的日常聊天分开；没有执行任何拟议模型动作。
