# v0.2.0 建筑建模教学试用版

本版以Pre-release发布，供建筑学生在独立学习项目中试用。

Skill提供建模方法和工作流程；要让Codex控制SketchUp，仍需另行安装并配置第三方SU MCP。安装Skill不等于已经连接MCP。本仓库不开发或重新实现MCP，不捆绑第三方软件。

## 本次新增

- 住宅路线：单户、指定标准层、首层／顶层差异、按需整栋；原创住宅片段含楼梯、板洞和阳台。
- 圈选截图＋参考样板：目标A参照B，保留指定尺寸与非目标构件，样板后处理授权范围内同类对象，给局部前后对照。
- 可选模型分工：Flash基础建模→Sol接手审查与优化，附两段提示词；按实际任务状态交接，不用反复试错验证模型上限。
- 项目本地习惯MD：读取、初始化、合并明确偏好；最新指令优先，可纠正和忘记。真实记录保存在使用者项目的`.su-modeling/`，不进入公开仓库或分发包。
- 连接教程同步维护者MCP0.4.0的依赖、成对升级、兼容与保存规则；已连接者先读版本与目标，跳过安装，不自动升级。

原CAD副本清理、天正局部导出、毫米模板导入、反复重选炸开、两段尺寸检查、封面与正反面、保存可编辑SKP的流程保留。

## 下载与使用

下载Release附件`cad-sketchup-mcp-v0.2.0.zip`，与`给同学Codex的试用提示词_v0.2.0.md`一起交给同学；校验文件为同名`.zip.sha256`。解压后按README安装整个Skill目录到学习项目`.agents/skills/`，调用`$cad-sketchup-mcp`。

包内仅22个白名单教学文件：规范、教程、原创练习和空白习惯模板；没有个人习惯记录、真实项目模型、聊天原图、私人配置或安装器。

## 检查与实际边界

已做格式、引用／TOML、分发白名单、隐私模式扫描、ZIP成员与字节一致性、隔离解压、原创DXF静态几何和文本桌面推演。文本推演不是独立模型执行或真实MCP调用；日常交流只作为方法来源。

新增住宅练习的真实CAD／SU导入、封面、三维构件与保存重开，圈选对应实体、模型交接与偏好执行的实际表现，以及不同电脑／模型的学生完成情况仍待验证。没有数据证明耗时、费用、准确率或返工率改善。不替代设计、结构或合规判断。

私人习惯只影响使用者项目，不自动修改公共Skill；更新公共版本需明确选取可分享的通用方法。发布本包没有安装软件、修改全局配置或操作真实CAD／SU模型。
