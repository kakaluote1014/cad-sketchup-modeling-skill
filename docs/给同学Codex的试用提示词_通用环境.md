## 2. 先只读检查现状与兼容性

检查实际 SketchUp 年份／构建、安装路径、已有 MCP 扩展和运行依赖，发现当前可用工具。这台电脑的兼容性尚未验证，不能按发送者或其他同学电脑的成功记录认定我这里也兼容。

Skill 提供方法，不自带 SU MCP。没有 MCP 工具或连接失败时，先按教程排查，不假装读取或建模；需要安装软件或修改配置，先把具体来源、版本、改动位置和影响说明清楚，由我确认。保留现有软件、插件和配置，不自行升级、卸载 SketchUp。

已有连接时，通过实际版本检查和当前模型信息读取确认；工具名以现场签名为准，教程对应 `get_version`、`get_model_info`。仅显示“已启用”、端口可达或 `units:mm` 都不足以证明模型可读或比例正确。已有连接正常就跳过重复安装。

坯子插件是可选辅助工具。已经安装就检查现有功能是否可用，不重复安装；没有就先使用 SketchUp 原生工具，不为本次练习强制安装。缺少工具能力、出现兼容错误时，说明具体原因和能继续完成的部分；需要我点击界面时给准确的小步骤，不把计划写成已经执行。未连接且发现缺少依赖时，列出缺少项、下载来源、版本、改动位置和影响，明确下一步，由我确认后再安装或配置；不要只让我打开 SketchUp 后等待连接。

## 3. 带我准备独立练习底图

使用包内 `assets/practice/practice-source.dxf`，保留原图作尺寸依据；清理参照仅供对照。先了解我现有 CAD 工具，再指导“原图旁复制平面 → 只清理副本 → 导出目标副本 → 新建毫米 SU 准备文件 → 按正确单位导入 → 反复重选炸开 → 测两段已知尺寸 → 封面与正反面检查 → 保存底图 SKP”。

有天正时沿用教程的“文件布图 → 局部导出”，核对本机菜单与选项；没有天正则按普通 CAD 的可用导出方式准备目标 DWG，不强制安装天正，也不把 DXF 改后缀冒充 DWG。

封面可用已有坯子插件辅助，也可使用 SU 原生工具；都要检查闭合、共面和缺线。有图纸依据才补线，不封死门窗开口，不把房间地面、门弧或窗符号当墙。已经准备好的步骤只复核，不强制重复炸开或缩放。

## 4. 确认目标后再分步建模

建模前让我明确确认目标是新建的独立练习文档；随后我授权你仅在这个练习范围内按规范协助建模。每次写入前重新读取文档、目标、尺寸、位置和变换，保留人工移动、复制或炸开的改动，不能使用过期实体信息。

尺寸以 `practice.md` 的本练习表为准，不猜“常见尺寸”。表中的位置是局部坐标，复制或移动后要对应当前现场。先备份当前状态，做一段墙样板，报告实际厚度、高度和位置；客观检查通过后继续本次练习的同类墙体。

墙体阶段完成再补门上墙、窗台墙和窗上墙，保留净洞口。只做练习要求的构件，不自动追加门扇、窗框、玻璃、柱、屋顶、坡道或材质。转到我自己的项目时重新核对该项目参数，不沿用练习尺寸。

优先使用 SketchUp MCP，尽量减少 computer use。保存和预览前先检查现场可用的 MCP 工具与已获准能力，不因没有专用按钮就立即转向界面操作；确需界面操作时说明原因，减少重复切视图和截图。保留必要的目标、尺寸和保存检查。修改超时先检查实际状态，不盲目重复创建或直接撤销。每阶段保存可编辑 SKP，确认文件实际存在且非空，给简短尺寸检查、预览、备份位置和待核项。
