## v0.1.0 历史记录

版本 v0.1.0，日期 2026-10-08。验证的是教学规范 Skill，不是 MCP 实现。

### 首版范围

只读写本交付独立目录内的文档和合成测试数据；不运行历史模型脚本，不调用真实 CAD／SU，不安装软件，不改 Codex 全局配置。实机安装、建模及学生试用另行安排和授权。

- 8 个教学文件的 UTF-8、YAML 前置信息和界面信息、13 处本地引用、1 个 TOML 配置示例：通过。
- 分发白名单与私人路径／典型密钥格式检查：通过；包内无模型、RBZ、MCP 源码、配置备份或执行脚本。
- ZIP 完整性、逐文件字节核对，以及隔离目录 `.agents/skills` 解压复核：通过。这是文件层面安装检查，未测试 Codex 界面发现。
- 原工作区 97 个文件的 SHA-256 与制作前记录一致；没有调用真实模型工具。

最初的校验解释器缺 PyYAML，后来使用机器上已有的 Python 3.13 与 PyYAML 6.0.3 完成检查，没有为此安装依赖。静态校验只能检查文件结构，不能证明课堂可用性。

### 首版行为演练

两名独立评估代理各自只读实际 Skill、按需教程和合成现场，逐案记录下一步、模拟动作、写入范围与学生回复；维护者阅读输出作语义检查。未向评估者提供预设答案，没有用关键词检查冒充行为验收。

| 场景 | 观察到的规范行为 |
|---|---|
| 未连接 MCP | 进入安装／排查，不假装建模，不自动安装 |
| 已连接、底图就绪 | 跳过安装，先核目标与尺度，按本项目尺寸做样板 |
| 不闭合墙线／未知墙高 | 定位缺口和语义，补依据，不盲目封死或批量拉高 |
| 人工移动、炸开 | 不用失效 ID，重读现场，保留人工改动 |
| 指定首层且共享组件 | 检查父／子共享定义，隔离相关实例，保留标准层 |
| 旧项目柱尺寸 | 不当通用默认值，补图纸或具体示意授权 |
| 错误尺度 | 识别两段倍率冲突，先诊断，不缩放已有成果 |
| 多窗口／副本歧义 | 先确认文档、连接、选中范围，不任选副本 |
| 修改超时 | 先读实际状态，不整批重做或盲目撤销 |
| 立面材质含玻璃 | 分墙／框／玻璃、查共享与透明度，不统一涂整组 |
| 天正菜单不同、无胚子助手 | 保留局部导出范围，核版本；可选工具不是连接依赖 |
| 要求未验证的成功宣传 | 如实列待验证，不宣称兼容或效率已证明 |

12 个独立场景的决策符合上述主要验收约束。演练发现样板继续条件和纯材质任务尺寸前提可能让学生多等一次，已缩小这些门槛并做定向复测：整阶段已授权、样板客观检查通过可继续；仅调颜色／透明度且不改几何、不依赖物理尺寸时，报告尺寸状态，不因无关尺寸问答停工。

原始输入、两份输出、复测与维护者验收保存在仓库的 `validation/` 中，未放入学生分发 ZIP。仓库新增的打包检查结果为 `validation/package-check.json`，只代表该次文件检查，不自动重跑行为演练。**这些演练不是实际 MCP 调用、几何建模测试或学生试用。**
