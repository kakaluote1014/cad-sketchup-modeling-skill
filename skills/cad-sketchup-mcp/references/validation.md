# 验证说明

当前本地迭代 v0.2.0，更新日期 2026-10-29。文件检查、合成演练、用户反馈和独立实机验收分别记录；历史检查不冒充本轮实机结果。

## v0.2.0：住宅路线与0.4.0资料同步

新增住宅单户到指定楼层的路线、人工改动后续建步骤、原创住宅片段和自选三层差异任务；原CAD准备与入门资产保留。安装示例核到MCP0.4.0的固定发布版，但本轮没有安装、改配置或调用真实模型。

住宅资产实际做了静态DXF墙域／符号／板洞／楼梯平面核对、原图与清理参照的非注释几何对比、PNG解码与目检；并用7个内存损坏反例检查静态检查器能否拒绝错误。高度只作给定数值的算术检查，非三维实测。

新增10案文本桌面推演，检查版本混用、住宅分阶段、尺度／缺线、人工续建、目标歧义、共享定义、楼梯板洞及超时的决策。由维护者Agent生成并语义复核，不是独立Agent、实际MCP或学生试用。记录见仓库 `validation/behavior-v0.2.0.md`。

同版补充圈选截图＋参考样板的局部修改教程，并新增6案文本桌面推演，覆盖叠置构件、A/B尺寸差异、共享影响、定位歧义、同类批次和只看图讨论。方法来自用户与朋友的正常聊天，不把这段聊天当作v0.2.0实机验收；新增推演也是维护者自审，没有执行模型动作。

同版加入Flash基础建模→Sol接手审查与优化的可选方法与两段提示词。新增H1–H4四案维护者文本桌面推演，涉及反复错误与未知依据、交接后现场变化、在途超时与单一写入者、只读审查及设计边界；不实际调用指定模型，不比较能力、速度或费用。

补充项目本地习惯MD与空白模板，新增P1–P3三个维护者文本案例。仓库本地私人记录实际创建且Git排除，重复初始化不覆盖；检查分发白名单不含真实偏好。此文件操作检查不证明其他Agent会自动准确学习，跨客户端与真实使用仍待验证。

文件格式、引用、TOML、22成员ZIP、隔离解压和受保护文件检查见仓库 `validation/review-v0.2.0.md`、`validation/package-check.json`、`validation/residential-geometry.json`。静态通过不承诺Codex自动发现或所有模型自觉遵守。

**待验证**：新住宅DXF在真实CAD／天正／SU中的导入与封面、一层和三层的实际尺寸／楼梯连通／可编辑SKP、人工移动炸开后续建、圈选图对应实体及局部修改的实际执行、重要保存重开、不同SU／模型环境及学生完成情况。真实测试需在单独授权的练习模型中进行。本轮没有相应结果。

## v0.1.2：批量展开与交付保护

本轮只更新教学文件、打包工具和隔离验证，不连接或修改 CAD／SU，不运行历史建模脚本，不改配置、不安装依赖、不提交推送。CAD 准备与连接教程、原始练习资产和旧 ZIP 保留；新增按需进阶参考，共 13 个 Skill 分发文件。

新增按任务影响选择检查深度、多层差异与共墙、墙板洞口楼梯联合核对、源对象隔离、互斥场景、安全保存切换和简短交付。技术参考明确单位边界、operation 不可嵌套、`page.layers` 不等于隐藏标签列表、以及文件 SHA 与几何指纹的不同含义。

本轮执行 skill-creator 格式检查、文件引用与分发白名单检查、ZIP 完整性／逐成员字节及隔离解压检查，并比较受保护教学文件的更新前后 SHA。原始输出与结果见仓库 `validation/review-v0.1.2.md`、`validation/package-check.json`。

新增 14 个合成场景的维护者桌面演练，逐案记录输入、具体下一步与保护范围，再作语义复核；见仓库 `validation/behavior-v0.1.2.md`。它不是独立评估 Agent 运行、真实工具调用、几何测试或学生实机测试，没有用关键词匹配代替判断。新规则的真实执行效果仍待授权后的实机验证。

## v0.1.0 历史记录

版本 v0.1.0，日期 2026-10-08。验证的是教学规范 Skill，不是 MCP 实现。

### 首版范围

只读写本交付独立目录内的文档和合成测试数据；不运行历史模型脚本，不调用真实 CAD／SU，不安装软件，不改 Codex 全局配置。实机安装、建模及学生试用另行安排和授权。

### 首版文件检查

- skill-creator 的 quick_validate：通过，输出 `Skill is valid!`。
- 8 个教学文件的 UTF-8、YAML 前置信息和界面信息、13 处本地引用、1 个 TOML 配置示例：通过。
- 分发白名单与私人路径／典型密钥格式检查：通过；包内无模型、RBZ、MCP 源码、配置备份或执行脚本。
- ZIP 完整性、逐文件字节核对，以及隔离目录 `.agents/skills` 解压复核：通过。这是文件层面安装检查，未测试 Codex 界面发现。
- 原工作区 97 个文件的 SHA-256 与制作前记录一致；没有调用真实模型工具。

最初的校验解释器缺 PyYAML，后来使用机器上已有的 Python 3.13 与 PyYAML 6.0.3 完成检查，没有为此安装依赖。静态校验只能检查文件结构，不能证明课堂可用性。

### 首版行为演练

两名独立评估代理各自只读实际 Skill、按需教程和合成现场，逐案记录下一步、模拟动作、写入范围与学生回复；维护者阅读输出作语义检查。未向评估者提供预设答案，没有用关键词检查冒充行为验收。

| 场景 | 观察到的规范行为 |
|---|---|
| 未连接 MCP | 进入安装／排查，不假装建模，不自动安装 |
| 已连接、底图就绪 | 跳过安装，先核目标与尺度，按本项目尺寸做样板 |
| 不闭合墙线／未知墙高 | 定位缺口和语义，补依据，不盲目封死或批量拉高 |
| 人工移动、炸开 | 不用失效 ID，重读现场，保留人工改动 |
| 指定首层且共享组件 | 检查父／子共享定义，隔离相关实例，保留标准层 |
| 旧项目柱尺寸 | 不当通用默认值，补图纸或具体示意授权 |
| 错误尺度 | 识别两段倍率冲突，先诊断，不缩放已有成果 |
| 多窗口／副本歧义 | 先确认文档、连接、选中范围，不任选副本 |
| 修改超时 | 先读实际状态，不整批重做或盲目撤销 |
| 立面材质含玻璃 | 分墙／框／玻璃、查共享与透明度，不统一涂整组 |
| 天正菜单不同、无胚子助手 | 保留局部导出范围，核版本；可选工具不是连接依赖 |
| 要求未验证的成功宣传 | 如实列待验证，不宣称兼容或效率已证明 |

12 个独立场景的决策符合上述主要验收约束。演练发现样板继续条件和纯材质任务尺寸前提可能让学生多等一次，已缩小这些门槛并做定向复测：整阶段已授权、样板客观检查通过可继续；仅调颜色／透明度且不改几何、不依赖物理尺寸时，报告尺寸状态，不因无关尺寸问答停工。

原始输入、两份输出、复测与维护者验收保存在仓库的 `validation/` 中，未放入学生分发 ZIP。仓库新增的打包检查结果为 `validation/package-check.json`，只代表该次文件检查，不自动重跑行为演练。**这些演练不是实际 MCP 调用、几何建模测试或学生试用。**
