# 住宅路线：从一户到指定楼层

供学生做住宅作业、AI 处理单户／多层或人工改动后续建时读取。先按 [通用建模规则](modeling.md) 核对当前文件与目标；这条路线不要求一次建完整栋，也不代替户型、交通、结构或规范设计。

## 给学生的最少输入

已有图纸直接给图纸，不要求重新填表。只补影响下一步的缺项：

- 做哪一户、哪一层或哪个旁置副本，本次做到墙／洞口／板／楼梯的哪一步。
- 尺寸依据：两段平面控制尺寸、墙厚；做竖向构件时需要本层基准、层高、板厚／墙顶关系、相关门窗底顶。
- 哪些设计不能改，哪些具体部分允许示意；没有首层、顶层或剖面资料时先做已有依据的部分。

> 使用 $cad-sketchup-mcp。我已准备好底图。这次只做我选中的标准层墙体和洞口，尺寸以这组平面、剖面标注为准；右侧首层副本保留。请先读取目标与两段尺寸，做一个样板，通过检查后继续已授权范围。

项目图纸不全时，不因随包练习有参数就套用。平面能识别门窗位置，不代表能推断窗台、层高或楼梯踏步。

## 按本次目标选择进度

| 目标 | 怎么推进 | 到这里才算这一阶段完成 |
|---|---|---|
| 一户／教学片段 | 墙体样板 → 同类墙 → 门窗及上下墙；板、阳台只在要求时进入 | 关键净宽、厚高、开口贯通可测；房间和门窗符号没误拉高 |
| 一个标准层 | 先做代表户，再按图布置其余户及交通核 | 共墙只建一份；走廊、楼梯口与户门对应；板洞和阳台分开表达 |
| 首层／顶层副本 | 从已检查的标准层复制，但先确认差异 | 首层入口、架空等按首层依据；顶层楼梯终止、屋面按顶层依据，未知不补画 |
| 指定整栋 | 列清所需楼层及各自标高，代表层通过后分批复制 | 每层高度与差异、竖向连通、末层终止、受保护副本均已检查 |

整阶段已授权且样板客观检查通过，可连续完成同类构件。若用户说“样板让我确认后再继续”，才在该处等反馈；不能把授权标准层当成授权整栋。

## 住宅中容易漏的关系

**共墙与复制**：按图确认共墙归属，一侧负责或设独立共墙组；相邻户型各自带墙时先查重叠。镜像后核入户门、阳台方向、面朝向和变换。局部修改首层／顶层前查共享父级与子定义，只隔离会传播的编辑，不让修改标准层的窗台影响别层。

**墙、板和标高**：先约定本层 Z=0 指完成面还是结构面，层高不直接等于墙高。给定上层板底时，墙顶到板底还是通高按图处理；上下层共用楼板约定只由一层或独立板组拥有，避免每层复制出两块。板厚、板顶与阳台高差未知时不猜值。

**洞口与阳台**：分别读门洞、窗洞、窗台和上墙；门洞下不自动补窗台墙。阳台推拉门、阳台板、栏板分别编组；推拉门符号不能拉成实墙，阳台板不能封住门口。封闭阳台、地漏、找坡等须有要求和依据才加。

**楼梯与板洞**：区分“楼梯符号可见”“楼梯实体已建”“上下层可通”三件事。根据剖面或明确尺寸核起点、上下层标高、总高差、跑数、踏步分配、平台及洞口；只给外包络时可留独立占位，未经允许不当成真实楼梯。逐层检查板洞没有被整块楼板盖住；首层不复制向下悬空的一跑，顶层不复制继续向上的一跑。几何连通不等于净高、疏散或结构已验算。

## 人工改过后，“继续”的具体做法

1. 用当前路径、选中范围、父级与位置重新定位。多个同名副本或另开窗口时，先读成功的模型与学生指定目标一致；有歧义请学生选中。不要按旧名称、旧 ID 或世界原点猜。
2. 比对本次相关的实际变换、开口位置、已有构件和保存状态。人工移动后保留新位置；炸开后重新识别现有几何，不按旧组清单重造；图纸与人工修改冲突时只核对冲突处。
3. 保护包含未保存修改的当前状态。局部续建要检查共享定义、邻接板墙；旧脚本不整段重跑。
4. 只补差额。结束时读回目标与至少一处受保护相邻层／副本的相关状态，给当前 SKP、简短尺寸结果和局部预览。重要交付再安全重开；不能重开标待核。

> 我刚把首层副本移到右边，并炸开了一组窗墙。继续前请重新读取，不移动回去、不重建原组。这次只补我选中门洞的门上墙，保留手工修改和其他层；尺寸以这次标注为准。

## 自己检查，不需要复杂验收表

看平面和剖面／轴测：有没有重复共墙、封住的门窗或板洞、悬空楼梯、阳台与户型错接？再读关键尺寸、标高和目标位置。保存可编辑 SKP，检查墙、板、楼梯、阳台可单独选取；“看起来像住宅”不能代替尺寸回读。

第一次练关系可用 [住宅教学片段](residential-practice.md)。把“人工移位／炸开后续建”和“首层／顶层有差异”作为下一次实际试用任务；本轮没有在 SketchUp 中执行这些操作，不能声称续建保护已实机通过。
