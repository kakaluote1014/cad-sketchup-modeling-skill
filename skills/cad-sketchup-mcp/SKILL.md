# CAD → SketchUp MCP 建模教学规范

Skill 提供建模方法和工作流程；要让 Codex 控制 SketchUp，还需要安装并配置 SU MCP。安装 Skill 不等于已经接通 MCP。

这是教学与协作规范，使用现成 MCP 的能力，不实现或替代 MCP。目标是从连接、准备底图走到一层尺寸可核对、能继续编辑的白模。人决定设计与结构，AI 辅助识别、建模和检查，不承诺自动零错误。

## 从学生当前进度开始

先按 [快速开始](README.md) 匹配学生的连接、底图状态或已有模型局部修改任务；已明确进度则直接进入，不重问。利用已给信息和只读检查，只补问影响下一步且无法查清的内容。

首次或继续使用时，按 [本地习惯记录](references/preferences.md) 读取当前学习项目的`.su-modeling/preferences.md`；不存在时在已选项目安全初始化，已有不覆盖，用户不想记录则跳过。只合并明确的协作偏好，排除私人记录的提交与打包；最新指令优先，项目尺寸不变成通用习惯。

学生想先走通流程时，读 [第一次练习](references/practice.md)，提供随包原创 DXF、尺寸示意和分步指令。只在学生选用该练习时应用其尺寸；转入自己的图纸后不沿用练习参数。文件已生成不代表真实导入、建模或学生试用已完成。缺信息优先请学生给图纸、尺寸、标注截图或位置说明，不要求复杂表格。

- 未连接／连接失败：读 [安装与连接](references/install-connect.md)，先检查现有环境。工具列表出现或端口可达不等于能读模型；未读成功前不宣称建模。不擅自安装、升级、卸载或改配置。
- 已连接：成功读取版本与当前模型后跳过重复安装。
- 底图尚未准备：读 [CAD → SU 底图准备](references/cad-preparation.md)，保留原图和用户的天正局部导出流程。
- 底图已准备／继续建模：读 [分阶段建模](references/modeling.md)，先查尺寸和目标。不强制重复清理、炸开、缩放。
- 圈选截图、参照样板或已有模型局部修改：读 [圈选与局部修改](references/local-edit.md)。画框指位置，文字定动作；映射到当前模型后只改指定对象，不把框内所有构件一起处理。
- 学生选择先建基础白模、再换模型审查优化：读 [可选模型分工与交接](references/model-handoff.md)，带当前成果与依据交接，接手重读现场，同一时刻只让一个Agent写入；不默认切换模型或修改配置。
- 住宅单户、标准层、首层／顶层或整栋：按需读 [住宅路线](references/residential.md)，只推进用户要求的范围；想练楼梯、板洞与阳台时选 [住宅教学片段](references/residential-practice.md)，不把练习参数用于真实项目。
- 多栋多层、外观副本或场景交付：仍从分阶段建模开始；遇到保存切换、嵌套坐标、共享定义、显隐或指纹问题时，按需读 [进阶执行细节](references/advanced-execution.md)，不要求新手预读。
- 学生安装或第一次发指令：看 [快速开始](README.md)。核对技术依据或验证现状时读 [来源](references/sources.md)与 [验证说明](references/validation.md)。

## AI 每次写入前遵循

1. 优先 SketchUp MCP，尽量减少 computer use。重新读取当前文档、实际尺度、目标楼层与副本、选择／编辑上下文；结合路径、位置和层级定位，不能只凭名称或旧实体 ID。
2. 底图几何初检、尺度存疑或几何尺寸修改前，核对两段有原图依据的已知尺寸。每次写入都核实当前目标、变换与尺度状态。只调颜色／透明度且不改几何、不依赖物理尺寸时，可沿用同文档的校验记录；没有记录如实说明尺寸未校验，不把与该修改无关的尺寸问答当作停工条件。纹理物理尺寸等依赖尺度的操作仍先核对。MCP 的 `units: mm` 不证明比例正确；以最新明确图纸、尺寸和修正为准，冲突先核对。
3. 区分墙体、房间地面、门窗符号、楼梯、电梯和投影线。不闭合、不共面、未知尺寸或错误尺度时先定位问题，暂停受影响部分，不盲目批量拉高全部面。
4. 修改前保留可恢复备份；先检查或做一处小样板，核对尺寸、位置和开口，再处理已确认的同类构件。对象独立可编辑。
5. 人工移动、复制、炸开、换窗口后重新读现场，保留人工改动。目标有歧义时只检查，请用户选中或说明。局部修改复制组件前检查共享定义，避免影响其他楼层。

## 按要求推进并交付

先区分已确定设计、可逆实现选择与待定设计。按任务影响选择检查深度；整阶段已授权、样板客观核对通过后连续推进。关键依据不足只暂停受影响部分，不把未知设备参数变成全项目停工，也不要求学生先交 JSON、坐标表或哈希报告。

常用顺序：墙体 → 门窗及洞口上下墙 → 阳台／入口坡道 → 柱子 → 屋顶及排水 → 材质。按实际需要调整，只进入用户要求的阶段。

门上墙、窗上墙、窗台墙不能漏；阳台玻璃推拉门、楼板和栏板分别表达。材质区分墙体、窗框、玻璃，不把玻璃统一涂成不透明墙面。

墙高、墙厚、柱截面、坡道、栏板均无通用默认值。不把历史案例或“常见尺寸”当图纸事实。近似布置须获用户明确允许，标为示意、保持独立可编辑。

超时后先读实际状态，不盲目重发修改或撤销。每阶段保存可编辑 SKP，给简短检查结果、预览和待核项；确认文件确实保存，临时导出不等于最终交付。重要批次在保护未保存成果后验证保存重开，检查受保护对象及相关场景。交付指向一个当前模型入口；检查深度与任务相称。区分静态校验、合成演练、用户反馈和独立实机验收，未执行的如实标为待验证。
